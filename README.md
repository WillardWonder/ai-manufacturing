# AI for Manufacturers

A plain-language overview site for a lecture audience: what AI is, the tools, what it can do in a manufacturing shop, a worked example (turning an expert's knowledge into a work instruction), guardrails, where to start, and prompts to keep.

Live at https://willardwonder.github.io/ai-manufacturing/

- `index.html`: the overview
- `handout.html`: one-page take-home sheet with QR code
- `assets/`: styles, script, QR code. No build step.
